# 籃球人生 V6.11｜原創品牌安全化版

這是一款原創籃球生涯模擬遊戲。

## V6.11 調整
- 遊戲公開顯示不使用現實職業聯盟、學校體育組織與國際籃球組織的正式品牌名稱。
- 美國職業層級使用「美國職業聯盟／美國發展聯盟」等泛稱。
- 美國大學層級使用「美國大學一級／二級／三級聯賽」。
- 台灣高中層級使用「台灣高中甲級／乙級」。
- 國際賽改用「世界國家盃／國際資格賽窗口／世界綜合運動會籃球賽／洲際國家盃」。
- 球隊與球員維持虛構／程序生成，不使用現實球隊 Logo 或球員照片。
- 新增「非官方、無授權關係」聲明。
- 保留現代籃球的賽季、交易、選秀、國家隊、二隊與教練等遊戲機制。

## 原創原則
制度與籃球概念可以作為模擬基礎，但程式碼、介面、美術、故事文字、球隊品牌、球員與素材應維持原創。


## V7.0 現代籃球大型更新
新增 15 類現代籃球系統：
1. 動態 Archetype：依主要/進階能力、位置與發展重新計算。
2. 11 項進階能力。
3. 9 種戰術與戰術適性。
4. 先發、第六人、主要替補、輪替、板凳、二隊與 MPG。
5. 火熱/低潮/疲勞/傷病/士氣/合約年/季後賽狀態。
6. 國家隊候選→集訓→12人名單。
7. 年齡、潛力、表現、傷病、名氣構成市場價值。
8. 新秀/球員選項/球隊選項/提前續約/短約/頂薪/底薪/自由球員/RFA 類型。
9. 隊友、教練、管理層、球星招募、球迷關係。

13. 多類型傷病與上陣/休養/復健/手術。
14. 選秀五階段架構與落選後發展聯盟/海外路線。
15. 二隊下放與召回機制。


## V7.1 心境・休閒・感情更新
- 新增心情、壓力、體力、孤獨感四項生活狀態。
- 心境對球場表現採平衡型修正，約 -10%～+10%，不會蓋過真正的球員能力。
- 每年自然累積比賽/訓練壓力；整年沒有休閒會額外產生心理疲勞。
- 新增打電動、電影、朋友聚餐、音樂/演唱會、小旅行、閱讀/咖啡廳、完全休息、陪伴家人等休閒。
- 休閒消耗年度動作次數，因此需要在訓練與生活間取捨。
- 新增感情系統：單身、認識新朋友、交往、約會、溝通、陪伴、私人空間、分手。
- 感情穩定可小幅支持心境；關係不穩定或分手則可能短期影響心情與球場表現。
- 感情成功率會參考人際關係與知名度，但不保證成功。


## V7.2 婚姻・離婚・感情新聞更新
- 感情系統新增「結婚」：交往至少一年後可討論婚姻，成功率依親密度、穩定度與交往年數判定。
- 已婚後新增婚姻年數、婚姻溝通與離婚選項。
- 結婚、分手、離婚與重大感情風波都有機率登上新聞。
- 新聞曝光率會受到玩家知名度與職業階段影響；職業球員與高知名度選手更容易被媒體關注。
- 新增低機率突發「感情不忠／外遇風波」，可能由玩家或伴侶一方發生。
- 玩家面臨自身越界事件時，可選擇坦白、結束並沉默、或繼續隱瞞；不同選項影響伴侶關係、壓力、心情、球迷支持與管理層關係。
- 若伴侶出現不忠事件，玩家可選擇溝通、分手或暫時分開。
- 重大感情新聞會增加知名度，但可能降低球迷支持、管理層關係與短期球場狀態。
- 感情事件維持低機率，避免喧賓奪主；籃球仍是核心玩法。


## V7.3 代言・財富系統
- 新增獨立財富數值與生涯代言收入。
- 新增運動鞋、飲料、運動用品、科技、汽車、時尚、餐飲、娛樂、金融、精品等原創泛稱品牌。
- 代言邀約依知名度、球場能力、球迷支持、心境與人際關係計算。
- 商業型經紀人可提高代言簽約成功率。
- 合約包含年薪、年限與部分績效獎金。
- 每年自動支付有效代言收入，合約到期後退出。
- 新增保守儲蓄、投資理財、高額消費、公益活動。
- 高額消費可改善心情；公益可提升知名度與球迷支持；投資有賺有賠。
- 財富越高會產生合理的年度生活支出。

## V8.1 專業・簡易教練模式
此模式只有球員退役後選擇「退役後執教」才會開啟。

核心設計：
- 主操作簡化為：賽季開始、陣容、戰術、球員、補強。
- 額外低頻功能收進「教練生涯」，避免畫面過度複雜。
- 教練能力簡化為：進攻、防守、臨場、培養、管理。
- 陣容預設由助教依能力、狀態、戰術適性自動安排。
- 戰術只需選一種進攻與一種防守風格，不需要調複雜數值。
- 球員頁整合重點培養、教練進修、更衣室會談。
- 補強頁提供球隊需求提示，再進入交易市場。
- 復出、獎項、完全退役收進教練生涯頁。
- 球員時期原本的心境、代言、現代籃球等浮動入口，在教練時期隱藏，避免混淆。

## V8.4.5 教練自我訓練／復出準備
- 進入教練模式後，右側主要操作重新保留「訓練」。
- 此「訓練」是玩家本人自我訓練，不是訓練隊上球員，也不是教練能力訓練。
- 可訓練運球、彈跳、投籃、傳球、籃板，作為未來復出的準備。
- 每次消耗 1 次行動，成功率 80%；成功 +3～7，失敗 -1～2。
- 教練每年五項球員能力各 -2 的既有規則保留，因此自我訓練可抵銷部分退化。
- 只要五項能力尚未全部歸零，就能繼續自我訓練；全數歸零後依既有規則不可復出。
